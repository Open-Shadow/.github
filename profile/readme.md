# OpenShadow

> 一个专注于基础设施与开发者工具的开源组织。

我们成立于 2023 年，由一群热爱开源的开发者共同发起。我们的目标是打造一系列高质量的基础设施工具和开发者生态，让每一位开发者都能从中受益。

## 参与贡献

我们欢迎每一位开发者的参与，无论你是经验丰富的工程师还是刚入门的新手：

1. 浏览项目，找到你感兴趣的仓库
2. 阅读项目的 README 和 CONTRIBUTING 文档
3. 选择一个标记为 `good first issue` 的任务
4. 提交 Pull Request，等待代码审查

**贡献方式：** 提交代码 · 完善文档 · 报告问题 · 社区交流 · 推广分享
